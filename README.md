# 像素迷雾世界

> 洪水淹没了家园，你漂到一片被迷雾笼罩的小岛。采集资源、驱散迷雾、抵御夜里的海盗，找到雾外的新大陆，造一只木筏离开。

4399 小游戏《像素迷雾世界》的网页重制版，手机和电脑都能玩，横屏竖屏都行，支持同屏双人。纯静态 HTML/CSS/JS，没有构建步骤，也不依赖服务器。

## 玩法

- **自动采集 / 战斗**：用摇杆或键盘移动，停在树、稻田、紫水晶旁边会自动采集；海盗靠近会自动挥剑；站在受损的营地旁会自动修理。
- **驱散迷雾**：9×9 共 81 块地块，开局只有中间 5 块。走到雾边会冒出气泡，花资源就能驱散，越往外越贵。
- **建筑**：木料场、粮仓、晶矿场会自动产出资源，并能升级“储量 / 再生速度 / 精灵负重 / 每次采集量”；集市可以升级武器、兑换资源。
- **小精灵**：在营地召唤小精灵并指派工作，它们会自己去采集、搬回营地，遇到海盗也会帮忙打。
- **昼夜与海盗**：每天 160 秒白天 + 60 秒黑夜。天黑后会收到海盗来信，接着海盗船从某个方向靠岸，冲向营地。营地被毁或玩家倒下即失败（每局可免费复活一次，之后花金币复活）。
- **4 个异世界**：迷雾里藏着 4 个神秘洞窟，各是一个小游戏——
  - 危险世界：躲炸弹、激光、导弹，坚持 60 秒（奖励：神光剑，攻击翻倍）
  - 迷失世界：漆黑迷宫里找出口（奖励：一只精灵进化为森林先知）
  - 数字世界：读题，站到正确的数字砖上（奖励：金币）
  - 颠倒世界：方向全反，把水果放进传送带上对应的纸箱（奖励：精灵加速 + 金币）
- **结局**：找到新大陆并造木筏 → 结局一；先通关全部异世界 → 结局二；再驱散全部 81 块迷雾 → 结局三。登陆后可以选择结算，也可以继续探索。
- **8 个角色**：熊猫人、小呆开局可选，其余靠累计成就解锁（收集资源、击退海盗、通关异世界、达成结局）。各有特长：砍树快、收稻快、挖晶快、攻击强、移动快……
- **双人模式**：同一台设备两人合作。倒下的队友，另一个人站在旁边就能扶起来。

## 运行

- **本地**：直接双击 `index.html` 就能玩（全部是普通 `<script>`，不需要本地服务器）。
- **存档**：自动保存在浏览器 localStorage。单人、双人各一份进度；结局、角色解锁、最好成绩长期保存。
- **手机**：可以“添加到主屏幕”，像 App 一样全屏打开（自带 manifest 与离线缓存）。

## 部署到 Cloudflare Pages

1. Cloudflare 控制台 → Workers & Pages → 创建 → Pages → 连接到 Git，选择本仓库。
2. 框架预设：`None`；构建命令：留空；构建输出目录：`/`。
3. 保存并部署。之后每次推送到主分支都会自动更新。

`_headers` 已经设置好 JS/CSS 的缓存策略，更新后玩家刷新就能拿到新版本。

## 目录

```
index.html            入口
css/style.css         界面样式（像素风面板、HUD、弹窗、横竖屏适配）
js/util.js            数学、随机数、事件总线
js/data.js            数值表：营地/木料场/粮仓/晶矿场升级、海盗每晚数量、角色、任务、题库
js/sprites.js         像素美术：所有角色、建筑、资源、地面、云雾都由代码逐像素绘制
js/input.js           键盘 + 浮动摇杆（双人分左右半屏）
js/audio.js           WebAudio 实时合成的音效与芯片风背景音乐
js/save.js            存档
js/world.js           地图生成、可走判定、地块寻路、迷雾、地形绘制
js/entities.js        玩家、小精灵、海盗、海盗船、特效、海鸥/鲨鱼鳍/螃蟹
js/game.js            主玩法：经济、建造升级、昼夜、海盗来袭、任务、结局、夜间光照
js/minigames.js       4 个异世界小游戏
js/ui.js              HUD、交互气泡、各种弹窗
js/main.js            菜单、选角、剧情、结局图鉴、主循环
tools/autoplay.js     自动试玩机器人（平衡测试用，不随游戏加载）
tools/minitest.html   单独测试小游戏
tools/sheet.html      美术素材总览
```

美术全部是代码绘制，音效与音乐由 WebAudio 实时合成，仓库里没有任何图片或音频素材（图标除外）。原版的数值表（营地 / 三座产业建筑的升级曲线、每晚海盗数量、角色属性）沿用了原作的设定。
